Conditions d’utilisation

Les conditions officielles de REC BLUE n’ont pas encore été fournies par le responsable du projet.

Ce site présente actuellement le projet et ses images. Aucun achat, compte ou téléchargement du jeu n’est disponible ici.

Confidentialité

Ce site mémorise dans votre navigateur la langue choisie et votre préférence de notifications avec les clés recblue.language, recblue.updatePings et recblue.noticeClosed. Vous pouvez les effacer dans les données de site de votre navigateur.

Lorsque les comptes sont configurés, Supabase traite votre identifiant (pseudo, ou adresse email pour les comptes créés auparavant), votre mot de passe via son service sécurisé et votre profil (pseudo, rôle et date de création). Aucune adresse email n’est demandée pour créer un nouveau compte. Votre identifiant de connexion n’est pas affiché aux autres membres. Les administrateurs du site peuvent consulter les pseudos, identifiants et rôles des comptes. Le jeton de session est conservé dans le stockage local de votre navigateur afin de rester connecté, jusqu’à la déconnexion.

Aucun paiement ni suivi d’audience n’est intégré. Les liens externes, notamment Discord, ont leurs propres politiques. Contactez le responsable du projet pour toute demande relative à votre compte.

La politique officielle, les coordonnées du responsable et les informations relatives aux journaux de l’hébergeur restent à compléter avant publication.

Comment installer REC BLUE ?

Installation sur PC

Le guide sera à confirmer avec le lanceur officiel. Aucun téléchargement n’est disponible pour le moment.

  1. Téléchargez le lanceur depuis le lien officiel lorsqu’il sera disponible.
  2. Vérifiez l’éditeur du fichier et analysez-le avec votre antivirus avant de l’ouvrir.
  3. Ouvrez le lanceur et suivez les instructions d’installation.
  4. Si plusieurs modes sont proposés, sélectionnez le mode écran ou réalité virtuelle compatible avec votre matériel.
  5. Lancez le jeu depuis le lanceur officiel.

Gardez votre antivirus actif. Si un fichier est bloqué, ne contournez pas l’alerte : vérifiez sa provenance auprès de l’équipe.

Aucun injecteur ni exécutable non vérifié n’est proposé sur cette page.
